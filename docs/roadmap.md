# Roadmap

1. Bind undocumented display and touch interrupt lines from a full schematic or
   official Arduino board package.
2. Add concrete esp-hal constructors for SPI, I2C, PWM, ADC, and GPIO resources.
3. Complete BMI270 configuration upload and interrupt mapping.
4. Add LoRa support for SX1262 after the core SDK stabilizes.
5. Add optional BLE and 802.15.4 services.
6. Add hardware-in-the-loop CI scripts for Nesso N1 examples.
